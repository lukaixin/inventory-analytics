# 工程军规

1. 只在本项目内写入。父目录 `01_rawdata`、`isolated_versions`、`outputs`、`work` 是保护区，只读；验收前后记录文件 SHA256。不得覆盖或移动旧版本。
2. 先明确需求、口径和 API，再实现跨模块变更；变更契约须同步调用方、测试和文档。允许本轮必要技术选择，不把例行修复变成审批。
3. 用户最新决定：DuckDB是当前开发与验收数据库，使用持久化文件；PG为后续目标，保留已下载资产。迁移由Alembic管理，不在应用启动时drop/create表；连接/类型/锁方言集中隔离，单进程写入限制明确记录。
4. 业务空值保留 null，UI 显示“暂无数据”；禁止强转0。库存不跨时点求和，父子汇总不可相加，MWD 与库龄风险不可相加。
5. 历史转录与合成样例独立 dataset；所有页面展示来源类型、时间和版本。没有底层事实不生成假下钻，不把来源月份猜成年月日。
6. 导入先校验预览，提交原子化并保留版本；预览不得写入正式快照。文件大小、行数和字段类型必须有界；无效内容不得部分入库。
7. 查询/导出/导入共用服务端授权入口。开发身份仅允许本地开发；生产权限未配置时拒绝启动，不允许用户在浏览器自行扩大授权。
8. SQL 参数化；密钥仅在忽略的配置中；不输出连接密码、堆栈或原始数据库异常到网页。不修改用户级配置。
9. 源数据不可变，派生展示可重建。种子数据重复执行不重复写入、不删除历史记录。删除数据库、卷、历史版本或覆盖正式数据必须单独授权。
10. 构建通过不等于业务通过。必须有真实DuckDB迁移、数据核对、API/浏览器及重启持久化证据；未来PG迁移未运行须标明。
11. 子代理有明确文件所有权；不得撤销其他代理或用户修改。QA 独立检查，不自行修复其审查代码。
12. 默认仅本地运行；远程部署、发送消息、发布或推送不包含在本轮。新证据引起设计变更时记录决策及影响。
