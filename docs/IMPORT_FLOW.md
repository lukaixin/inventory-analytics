# 数据导入流程

当前只接规范JSON `canonical_json_v1`，evidence_level必须SYNTHETIC_DEMO。Excel字段映射待底表到位，不猜任意Excel列。旧转录通过专用只读seed适配，不经过用户通用上传。

1. 下载模板并填入记录，保留schema_version及series code。
2. 上传限制5MiB/10000条/32快照，解析并检查类型、金额、日期、重复/外键、数值闭合。
3. 预览只写ImportBatch，展示样本、计数、SHA、错误、重复版本；错误阻断提交。
4. 提交以import_id幂等，锁定导入批次，在一个数据库事务创建来源、不可变版本、快照和明细。
5. 默认set_current=false，保留已有当前版本；显式设true才切换，同series限制。
6. 刷新页面可选新版本；失败事务全部回滚，原版本不受影响。相同文件重复提交返回既有版本。

来源文件及内容不上传外部服务。历史转录、合成和未来正式ERP等级不得混用。任何自动系统适配器未来都必须进入相同校验/版本提交服务。
