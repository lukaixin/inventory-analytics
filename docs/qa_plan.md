# 验收计划

所有测试从本项目运行。后端必须连接隔离的临时DuckDB文件，不对开发数据做清空操作。PostgreSQL切换属于未来专项验收。

| 验收 | 证据 |
| --- | --- |
| 文档先行，原版本保护 | 文档基线时间和保护文件前后哈希 |
| DuckDB真实可用 | 引擎版本、migration head、readiness和重启后查询 |
| 样例可重复导入 | 第二次 seed 不重复，记录数和金额核对 |
| 四KPI/趋势/时点比较 | API固定输入断言，浏览器切换并观察数据变化 |
| 库存探索 | 范围/客户/物料搜索、分页、图表和明细联动 |
| 数据边界 | null不变0、历史未知年份、不同快照不混算、MWD不重复加总 |
| 导入 | 模板→无效内容报错→有效预览→提交→新增版本→刷新仍存在；预览前后正式记录数一致 |
| 授权接口 | 限定范围后查询/导出不可越权，生产无正式身份配置拒绝启动 |
| UI | 桌面截图、390px窄屏、无页面横向溢出、加载/空/错误、键盘标签 |
| API与前端 | 后端测试、OpenAPI、TypeScript检查、生产构建、浏览器无未处理错误 |

验收结果写 `evidence/` 和 `docs/project_status.md`，不预填成功。正式业务口径验收和58万行性能测试留待真实底表到位。
