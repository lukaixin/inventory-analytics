# 产品与交互冻结

主用户：管理层看趋势和比较、业务人员探索库存并核对来源、数据维护人员导入样例。目标是看清存量和变化，不宣称AI判断。

## 导航与主流程

五页：总览、库存探索、库龄、MWD专题、数据版本与来源。总览显示历史转录系列及四KPI，各有趋势图；可选范围、分析月、基期月，显示本期/基期/绝对变化/相对变化（基期0或null时比率无定义，显示—）。指标好坏未定的金额变化不自动染成风险红绿。

库存探索显著标注合成演示；选四时点中的任意分析和比较时点，选择分解维度/点击分组筛选，面包屑清除筛选，条形图显示构成和变化；表格呈现真实API明细及分页，支持搜索和导出。历史总览不无提示跳到合成明细。

库龄单独0829标签，按来源form/scope/category选组，条形图与桶表对应，明确总计/超180天与缺数/差额。MWD独立时间标签，显示来源层级汇总和可见明细；inventory与stock清晰区分，不把八层级加总。

版本页提供系列/版本列表、来源SHA、限制、核对事项和导入入口：下载规范JSON→选择文件→预览样本/错误→仅无错误可提交→显示新版本并刷新列表。已提交版本支持选择，set_current默认false。核对事项只读，不能假装业务已解决。

来源通过按钮/对话框查看原sheet/row/image/cell/value/note，可键盘关闭；来源引用缺失时给出明确空状态。

## 视觉与状态

深海军蓝#071426，面板深蓝，青色#35e0ff，橙色#ff9f43，正文#e8f4ff，次级#8fb0c9；少量L形角标和精简标题。中文正文>=14px，辅助>=12px，不使用emoji。图表为主要信息，禁止大段说明占满首屏。桌面紧凑清晰，390px布局换行，宽表仅表格内部横向滚动。

每页显示数据类型、版本和时间；合成橙色标记，转录为未逐格核对。加载、失败重试、空数据、无权限、导入校验错误有可见状态。所有筛选关联label，按钮可键盘触达，非hover唯一入口。数据未知显示“暂无数据”，0正常显示0。
