# 可移交的需求证据与边界

本页为可随源码移交的需求摘要。原始照片、对话留存、工作簿和本机验收截图不随Git仓库上传；`evidence/`为本机归档。它们不是新环境运行依赖。

## 功能依据

| 依据 | 已确认内容 | 限制 |
| --- | --- | --- |
| 用户最新指令 | 独立V7、先用DuckDB；保留PG准备资产；三核心页；总览必须直接展示结构与规则结论 | 工作电脑V6源码和真实ERP数据不可共享 |
| 原有页面照片 | 四KPI与Actual/Target/Forecast；基期比较；形态/业务线结构和月度展开；四快照分析；分层库存表、库龄、筛选、排序与导出 | 照片的数字和日期不作为新实现的真实数据或固定业务配置 |
| 已读取的V7架构说明 | React/FastAPI、服务端统一指标、数据管道与应用分层、授权与部署预留 | 企业服务器、身份与部署方式未定 |
| 已读取的V6快照说明 | CURRENT/MONTH_START/MID_YEAR/YEAR_START由manifest统一解析；内部日期与文件名冲突时拒绝；版本不可变 | 工作电脑Release与完整功能规格未验证 |
| 原对话历史留存 | 结构化数据和规则驱动异常标记；区分源数据、派生与合成数据 | 只确认规则方向，未恢复完整最新V6规则表 |

## 当前实现的事实等级

- 默认`management_demo_v1`为确定性合成演示，包含11快照、792库存事实、1232预计算指标事实、9目标和16预测；以生成器和清单实际校验为准。
- 历史转录只有本机私有副本，不属于全量ERP明细，也未获得业务签字。新克隆缺少该副本时不会自动补造。
- 三主页面：趋势总览、明细分析、库存数据表；旧转录/MWD/版本/导入在来源与专题。
- 当前重点结论是`management_overview_rules_v1`候选规则，条件与证据可查看，无LLM生成。正式启用仍须业务确认。
- 周转及平均库存是预计算不可加指标；时点库存按同一快照的授权事实聚合。未知不填0，份额、单位和期间严格区分。

## 尚未解决的业务输入

真实快照及别名、业务主键和批次粒度、组织/业务线映射、币种及计价、周转/平均库存字典、Target与Forecast来源和维度、原材料/半成品风险阈值、例外库存规则、MWD交集去重及正式权限目录均需真实材料支持。

正式接入步骤与mock退场清单见[REAL_DATA_ONBOARDING.md](REAL_DATA_ONBOARDING.md)。数据/API/规则契约用于防止当前候选实现的语义漂移，不等于企业业务审批。
